FAQ · 大家最关心的 3 个问题

隐私、费用与模型配置

1. 我的聊天记录和文件会上传到作者服务器吗？

完全不会。Nesti / ExplainLab 是 100% 本地开源软件，没有任何官方云端服务器，所有数据库、附件和 API Key 都在你自己的硬盘里，代码在 GitHub 完全透明可审计。

2. 不买 API Key 能用吗？

可以！新建笔记、网址剪藏、文件库原位阅读、乱文件夹哨兵、一键出 PDF/PPT/Word、全局闪记、知识星图、6 套皮肤全部免费离线可用；如需 AI 对话与自动提炼，可在软件「模型与 Key 设置」填入 DeepSeek 或直接连本机免费的 Ollama。

3. Claude 封号后，具体怎么把记忆接给 Cursor / Codex？

因为平时对话结论已沉淀在 Nesti 本地副库里，新工具安装后双击「一键接入本机AI助手.bat」挂上 MCP，直接让新助手调用 Nesti 检索或只读接力工具，1 秒就能拿到之前完整的架构决策与进度。
