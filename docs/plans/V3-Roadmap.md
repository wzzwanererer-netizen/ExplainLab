## 二、五大核心支柱详细设计

### 支柱 1：大小模型协同路由（Local Steward + Cloud Brain）
- **本地管家小模型（`STEWARD_*`，可选）**：对接本机 Ollama 或轻量 `llama-server`（推荐 `Qwen3-0.6B` / `Qwen2.5-1.5B` + `bge-small-zh-v1.5` / `Qwen3-Embedding-0.6B`，纯 CPU 可跑，~450 MB–1 GB）。
  - 负责 24h 后台免费脏活：文件自动归类、打 `#标签`、过滤低价值闲聊、重复/矛盾新陈代谢初筛、本地离线语义向量化。
  - **断网 / 不填任何云端 API Key 时依然完整运转**，私人文件与记忆 100% 不出本机。
- **云端主脑（`MODEL_*`，按需触发）**：仅在用户主动发起深度研究对话、长文档精读、测验出题或生成复杂交互沙盒时调用。
- **优雅降级**：未安装本地小模型时，无缝回退到纯规则 / 按需云端模式。

### 支柱 2：大肥鱼（DSH）/ Nesti 桌宠长期记忆海马体 & Claude 防封号保险箱
- **历史记忆一键抢救导入**：
  - 支持一键导入 `dsh-pet/memory.json`（拯救大肥鱼失忆）与本机 Claude Code 会话日志（`~/.claude/projects/*.jsonl`，防封号丢上下文）；
  - 导入结果按 Agent 自动归入专属副库（`Agent · DSH`、`Agent · Claude` 等），不污染主库。
- **新增两大专用 MCP 工具**：
  - `explainlab_recall_memory`：结合**语义相关性 + 最近活跃时间衰减**返回精炼 Top-K 记忆，专供桌宠/大肥鱼每次开口前低 Token 注入；
  - `explainlab_handoff_brief`：将项目过去沉淀的「架构红线 / 踩坑黑名单 / 当前进度 / 个人偏好」编译为精确 Token 预算（如 2K/4K）的高密度交接包，换新号或切模型 1 秒无缝衔接。
- **记忆新陈代谢**：结合 `contradicts`（矛盾边）与 `refines`（演进边），新结论推翻旧认知时在星图高亮冲突并弹出「认知演进裁决卡」。

### 支柱 3：乱文件夹哨兵（Folder Watcher）
- **严格只读，绝不改动原文件**；内置忽略黑名单（`node_modules`、`.git`、临时缓存、超大视频/安装包）与单文件大小上限（默认 20 MB）。
- **两级处理管道**：
  - **L1（免费秒级索引）**：监听新增/修改事件 → SHA-256 哈希去重 → 抽取 `.md / .txt / .pdf / .docx / .csv / 代码` 纯文本进本地 FTS5 索引 + 记录真实路径 `file://...`，支持 1 秒搜出文件藏身位置并**一键打开原文件所在目录**；
  - **L2（可控 AI 总结）**：按目录独立开关，由本地小模型（或云端队列限速）自动提炼摘要、标签与关联建议，默认进入草稿/审核队列。

### 支柱 4：交互式动态原理沙盒（Live Explain Sandbox）——知识不止于文字
- **核心理念**：静态文字只适合“存”，交互动画才适合“懂”。每条知识除了 Markdown 正文外，均可绑定/一键生成一个 **可交互动态原理沙盒**（如：TCP 三次握手丢包模拟、RAG RRF 权重滑块实验、排序/树结构单步演进、物理/数学函数可视化）。
- **安全与工程实现**：
  - 沙盒产物（单文件轻量 HTML/SVG/JS）作为知识条目的一等公民附件/扩展字段持久化存库，随知识版本一同快照与导出；
  - 前端在严格隔离的 `<iframe sandbox="allow-scripts">` 中渲染（禁用表单提交、禁用弹窗、禁止访问主应用 DOM/Cookie、无外网请求 CSP），保障本地桌面安全；
  - 支持在知识卡片内直接**全屏交互、调节参数、重新生成与微调**。

### 支柱 5：多 Agent 生态与开源增长闭环
- 面向 GitHub 与社区提供中英文双语 README、首页 10 秒动图演示、Qoder Sites 在线交互体验与便携安装包；
- 面向未来 **Nesti** 主生态：将 ExplainLab 作为 Nesti 的统一记忆海马体，直接赋能 Nesti 高帧 PNG 桌宠（如菲比）与桌面工作区。

## 三、分阶段实施路线（严格遵守 `AGENTS.md` 架构红线）

- **Phase V3-1（快速引爆 · 记忆海马体 & 防封号交接）**：
  - 本地小模型管家通道（`STEWARD_*` 双模型路由，兼容 Ollama / `llama-server`）；
  - `dsh-pet/memory.json` + Claude Code `.jsonl` 一键导入；
  - MCP 新增 `explainlab_recall_memory` 与 `explainlab_handoff_brief`；
  - 升级 GitHub 双语吸星 README + 动态 GIF + 社区推广。
- **Phase V3-2（核心灵魂 · 交互式动态原理沙盒 Live Explain Sandbox）**：
  - 知识条目沙盒存储与安全 `<iframe sandbox>` 渲染器；
  - 一键把任意知识条目/概念生成为可交互动态图解，支持全屏操作与二次微调。
- **Phase V3-3（日常刚需 · 乱文件夹哨兵 Folder Watcher）**：
  - `watched_folder` / `watched_file` 迁移表 + 增量监听与多格式文档抽取；
  - 前端「目录监听」管理页与一键打开原文件位置。
- **Phase V3-4（生态合体 · Nesti 高帧 PNG 桌宠接入）**：
  - 菲比高帧 PNG 桌宠状态机直接接入 ExplainLab 海马体。
