# 14 · Desktop Experience（Windows 桌面软件体验规范）

## 1. 键盘快捷键体系
| 快捷键 | 作用域 | 动作 |
| --- | --- | --- |
| `Ctrl + K` | 全局（Shell） | 打开 / 关闭全局命令与知识搜索浮层 |
| `Ctrl + B` | 全局（Shell） | 折叠 / 展开左侧模块次级导航 |
| `Ctrl + \` | 工作区 | 折叠 / 展开右侧上下文检查器 |
| `Ctrl + 1..7` | ExplainLab | 快速切换 7 个业务视图 |
| `Ctrl + Enter` | Chat / 编辑器 | 发送研究消息或保存知识修改 |
| `Esc` | 浮层 / 检查器 | 关闭命令浮层或取消编辑 |

## 2. 桌面级边界场景处理
- **文件拖放与原生选择器**：知识库表格与附件检查器支持拖放 `.md` / `.zip` 及 8 类白名单附件，拖入时呈现 `--nf-accent-border` 虚线投放区，严禁接受 SVG 或 >10 MiB 单文件（前置校验 + 后端权威校验双保险）。
- **高 DPI（125%–200%）与缩放**：全向量 SVG 图标 + 逻辑像素 `1px` 细线边框 + `Segoe UI Variable`，杜绝位图发虚。
- **长文本与大数据量**：表格行固定单行截断（`text-overflow: ellipsis` + `title` 悬停提示），正文与 Diff 区域独立滚动，未来正式实现时对 >500 条知识列表引入虚拟滚动。
- **本地后端服务断开**：底部状态栏绿点切换为红点「后端离线（127.0.0.1:8000）」，顶部展示可重试横幅并保留用户未提交草稿，不清空当前输入。
- **多标签与 Tauri 2 演进**：顶置 `34px` 标签栏已预留多文档并行能力；未来迁入 Tauri 2 时，Titlebar 左侧与右侧窗口按钮直接对接 Tauri `appWindow.minimize/toggleMaximize/close` 与原生拖拽区（`data-tauri-drag-region`），无需改动业务模块。
