# 剩余风险与复审边界

| 风险 | 对应设计边界 | 待验证 |
|---|---|---|
| SQLite 租约是逻辑锁，verify 与物理 syscall 间仍可能停顿 | 事务内最后核对、隔离后再复核和恢复。不承诺跨文件系统与 DB 原子性。 | LCK-04/05/08、GC-06/07/10 |
| PG 会话故障、阻塞预算、token 栅栏依赖真实驱动行为 | 单 guard 单专用连接、实际冲突域排序、断线失效和业务事务最后阶段 token 行锁。 | LCK-06/10，真实 PG 与故障注入 |
| Windows 占用、断电持久性和外部原地改写 | 同句柄输出、Windows 占用短重试、平台目录同步差异。外部拥有数据目录写权限的进程不由业务锁协调。 | ATT-09/12、GC-04–07、真实 Windows/POSIX |
| 崩溃残留与磁盘回收时延 | 先验证引用再操作隔离槽。坏 Hash、未知路径或人工态保留现场。临时文件崩溃残留只报告。 | GC-07/09/11、ORP-02/04/05/07 |
| 损坏的 pending 可能延迟 staging 清扫 | 不能证明无引用时保守保留，reject 仍可提交；清理由下一轮或运维接手。 | R1-IMP-10/11、R1.1-IMP-41/42 |
| 附件 ZIP 有产品侧限制 | 含附件限唯一文档，明确拒绝歧义。保留无附件批量路径、独立上传和原有 JSON 兼容。 | IMP-19、Batch A 回归 |

本轮仅进行设计静态检查，正式冻结与 B1 启动等待独立复审。
