def _origin_materialize_conflict(
    snapshot: dict[str, Any], records: list[dict[str, Any]]
) -> bool:
    """§22.2：ImportOrigin 与任意 COMMITTED MATERIALIZE 记录并存即冲突。"""
    return snapshot["import_origin_count"] > 0 and bool(records)

## P2：文件短写

### 新增统一封装

文件：`backend/app/services/file_write.py`

```python
def write_all(fd: int, payload: bytes | bytearray | memoryview) -> None:
    view = memoryview(payload)
    total = len(view)
    offset = 0
    while offset < total:
        try:
            written = os.write(fd, view[offset:])
        except InterruptedError:
            continue
        if written <= 0:
            raise OSError(errno.EIO, "write_all: os.write returned 0")
        offset += written
```

### 接入点

文件：`backend/app/services/source_identity.py`

- `JournalStore._atomic_write`：`os.write(fd, payload)` → `write_all(fd, payload)`（`:434`）。
- `JournalStore.archive_committed`：`os.write(fd, payload)` → `write_all(fd, payload)`（`:475`）。

文件：`backend/app/services/source_instance_id.py`

- `ensure` 临时文件：`write_all(fd, payload)`（`:121`）。
- `ensure` 无硬链接 fallback 正式文件：`write_all(target, payload)`，失败时删除半成品（`:135`）。
- `replace` 临时文件：`write_all(fd, (new_id + "\n").encode("ascii"))`（`:162`）。

### fallback 清理

```python
try:
    try:
        write_all(target, payload)
        os.fsync(target)
    finally:
        os.close(target)
except BaseException:
    # 不支持硬链接时只能直接写目标；失败必须移除半成品。
    with suppress(OSError):
        os.unlink(self.path)
    raise
```

保证：短写/0/异常时不会把截断文件发布为正式 ID；原 ID 不被覆盖。
