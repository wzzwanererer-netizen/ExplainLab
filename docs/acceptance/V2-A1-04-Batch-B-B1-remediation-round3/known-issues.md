# 待验证事项

- **PostgreSQL 实机与 POSIX 真机阻塞 B1 放行。** PostgreSQL 替身验证调用方超时、迟到清理所有权、失败分类和业务异常保真。真实半开传输、服务器何时观察到物理连接关闭、持锁端断开后的接管和各 SQL 等待上限仍需实机测量。
- **超预算后的清理。** 原生 psycopg 传输等待会按预算中止，客户端超时不会交付新的 guard。若驱动或平台调用无法立即中断，已有调用继续独占连接直至完成，清理由保留所有权的一侧执行。需要实机记录服务端锁释放的实际时间。
- **TOCTOU 边界。** 最后一轮 fencing 与文件 syscall 之间仍有冻结设计承认的窗口。前置拒绝和已观察到的失效必须阻断文件修改。
- **GC 端到端恢复。** quarantine 后记录前及 purge 后状态写入前的崩溃复盘按 B5 验收继续保留。
- **提交范围。** 本轮停在 B1，保留代码及证据供下一轮独立复审。
