# 阻塞与解除条件

- **优先复用现有 Ubuntu。** 当前需要一个能访问该发行版的获准执行会话。先在宿主交互会话核对 `wsl -l -v` 和实际 guest 入口。也可交付已有 Linux VM 的获准登录入口。没有足够证据证明需要安装发行版、启用 Windows 功能或改变宿主安全设置。
- **如仍需宿主变更，单独确认。** 提权只在确认确需查询或启动相关服务后考虑，影响限于该操作的执行权限。启用 Virtual Machine Platform 或 WSL 功能会改变 Windows 可选组件并可能需要重启。安装新 VM 会新增磁盘、内存与虚拟网络资源。先确定具体操作、原因和影响，再请求批准。本次没有执行这些操作。
- **两个验收门槛仍未关闭。** 原生 Linux/ext4、锁定安装、实际文件语义和 Journal 恢复均待验证。专用 PostgreSQL 实例、账号、真实双连接、锁与仓储 True PG 验收均待验证。
- **保留既有残余风险。** Round 3 的真实传输和 PostgreSQL 会话回收未验证。TOCTOU 的物理边界遵循冻结。GC 文件隔离后的完整崩溃恢复保留到 B5。
- **验收裁决。** 本轮没有新的真机失败足以归因到实现。两环境证据补齐后再交独立审计。
