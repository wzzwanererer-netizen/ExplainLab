# Nesti AI 工作空间 · 视觉设计系统（Nesti Fluent 2.0）

## 1. 品牌定位与视觉气质
- **品牌名**：`Nesti · AI 工作空间`（ExplainLab 作为 Nesti 的长期记忆与知识中枢）
- **品牌口号**：`把想法，交给我们一起实现吧。`
- **视觉气质**：**清透冰川机能风 × 编辑部精密留白（Airy Techwear Atelier）**
  - 参考 Nesti 官方设定图（白蓝机能外套、炭墨内搭、银白发色、极细工程标尺线、大片柔和冰雾留白）。
  - 既有二次元精品工作室的轻盈清透感，又具备 Linear / Apple / Craft 级别的桌面软件克制与专业度。

## 2. 官方核心色板（严禁偏离）
### 浅色模式（默认 · 冰川晨雾）
- **主色（Nesti 钴蓝 / 冰川蓝）**：`#3B74E8`（悬停 `#2B62D6`），辅助冰蓝 `#7BB8FF`
- **外壳冰雾底**：`#EDF3FC` → `#F4F7FD` 极轻对角光洗
- **主工作画布**：`#FAFBFD`（温润瓷白，禁止刺眼纯 `#FFFFFF` 铺满大背景）
- **纸面卡片**：`#FFFFFF` + 极细 `1px solid rgba(46, 51, 64, 0.08)` 描边 + 轻柔顶光
- **炭墨文字**：主字 `#1E2433`（呼应 Nesti 炭墨内搭与丝带）、次字 `#526077`、弱字 `#8896AB`

### 深色模式（极夜深海）
- **画布**：`#0D131F` / `#111827`
- **卡片**：`#151E2E` + `1px solid rgba(148, 163, 184, 0.14)`
- **主色高光**：`#5B91FF` + 冰蓝 `#8AC4FF`

## 3. 严格“去 AI 味”红线（强制遵守）
1. **禁止廉价蓝紫霓虹渐变**：不要给按钮、卡片边框、标题栏加高饱和紫粉霓虹发光。
2. **禁止卡片套娃**：最多 2 层视觉容器（画布 → 卡片），禁止 3 层圆角框嵌套。
3. **禁止满屏彩虹胶囊与滥用 Emoji**：状态统一用极简 `6px` 状态圆点或低饱和度单色微标签；界面标题与按钮克制使用线性图标，不堆砌杂乱 Emoji。
4. **排版必须有张力与呼吸感**：
   - 数字统计一律使用 `font-variant-numeric: tabular-nums` 等宽对齐；
   - 保留 Nesti 官方设定图里的**极细 `1px` 标尺分割线**与**微缩英文/等宽副标（如 `AI WORKSPACE · 01`）**作为标志性艺术细节；
   - 保证充足内边距与留白，信息分层清晰，一眼扫过去干净通透。
5. **官方二次元形象保护**：Nesti 官方立绘与 Q 版形象神圣不可随意篡改风格；软件工作台界面保持清爽克制，不硬塞喧宾夺主的桌宠控件（桌宠交互留给独立的 Nesti 桌宠程序）。
